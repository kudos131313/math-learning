# Triage Labels

各項工程技能使用五個標準分類角色。本表定義這些角色與本儲存庫實際使用之標籤字串的對應關係。

| 技能標準名稱（mattpocock/skills） | 本專案使用標籤      | 意義說明                             |
| --------------------------------- | ------------------- | ------------------------------------ |
| `needs-triage`                    | `needs-triage`      | 維護者需要評估此議題                 |
| `needs-info`                      | `needs-info`        | 等待回報者提供更多資訊               |
| `ready-for-agent`                 | `ready-for-agent`   | 規格已完整明確，可交由代理自動實作   |
| `ready-for-human`                 | `ready-for-human`   | 需要人工進行實作                     |
| `wontfix`                         | `wontfix`           | 不予處理                             |

當技能提及某個分類角色（例如「套用可供代理執行的分類標籤」）時，請使用上表中對應的標籤字串。

如需變更命名，直接編輯「本專案使用標籤」欄位即可。

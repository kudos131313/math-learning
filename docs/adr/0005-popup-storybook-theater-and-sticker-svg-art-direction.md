# 數學冒險島採用「立體繪本紙劇場」介面與「厚描邊繪本貼紙」向量美術方向

數學冒險島由早期單一「九九乘法冒險島」擴展為涵蓋三大海域（陽光加減群島、九九乘法奇幻群島、雲端應用王國）、無盡試煉塔與秘密樹屋的全站第五主分頁。原先 `css/mul-quest.css` 採用與全站隔離的舊版色票、`ZCOOL KuaiLe` 裝飾字型與深色木紋／街機漸層樣式；當題型擴展至二～三位數迷你直式加減、長句生活應用題與兩步驟分步引導時，舊版裝飾字型與深色木紋底板會降低國小二年級學童的識字易讀性，並與全站四大教學教室的「Hum 手作剪紙與厚磅卡紙（`css/tokens.css`）」視覺語言產生割裂。

因此我們決定將數學冒險島的整體美術架構確立為**「立體繪本紙劇場（Pop-up Storybook Theater）」**，並明定於 [美術風格指導規範](../art-style-guide.md)：

1. **介面殼層與全站 Hum 卡紙系統同源收斂**：淘汰 `ZCOOL KuaiLe` 字型與隔離舊變數，標題與題幹統一回歸全站圓體（`Chillax`、`Zen Maru Gothic`、`Noto Sans TC`），算式與鍵盤強制啟用 `tabular-nums` 等寬數字對齊；戰鬥題卡採用「木框鑲嵌厚白卡（Wood-Framed Cardstock）」，確保內芯恆為高對比暖白厚磅卡紙（`--color-card` + 紙張紋理），僅外框與 HUD 橫樑依四大場域（陽光琥珀、森林翠綠、雲端天青、試煉紫金）切換劇場主題色票。
2. **場景底圖與向量角色分層契約**：世界地圖與戰鬥背景採用「暖調柔光童話繪本插畫（`.jpg`）」並預留前景舞台構圖安全區；所有角色、15 位呆萌玩具魔王、15 隻守護小精靈与秘密樹屋家具統一採用「厚描邊繪本貼紙（Die-Cut Storybook Sticker SVG，暖深褐 `#332b22` 圓角粗描邊＋貼紙立體紙影 `--shadow-paper`）」。
3. **位值語意色絕對優先（Semantic Color Immunity）**：凡涉及十進位積木、迷你直式欄位與位值表徵的元素，永遠鎖定全站課本位值語意色（千位紫 `--th-*`、百位水藍 `--h-*`、十位暖橘 `--t-*`、個位石板白／灰 `--o-*`），絕不隨海域主題色變動。

## Considered Options

- **維持獨立街機奇幻風格與 `ZCOOL KuaiLe` 字型**：雖有街機小遊戲感，但 `ZCOOL KuaiLe` 在長句生活應用題中筆畫易糊成一團，且深色木板與街機霓虹漸層會干擾百藍／十橘位值語意色的辨識。
- **退回一般平面測驗白卡**：完全移除繪本舞台與木框劇場感，雖最易維護，但會喪失冒險島作為綜合闖關主單元的沉浸感與故事魅力。

## Consequences

- 新增 [docs/art-style-guide.md](../art-style-guide.md) 作為數學冒險島所有 UI、SVG 角色、樹屋家具、圖鑑卡片與戰鬥特效的單一美術驗收基準。
- `css/mul-quest.css` 的既有隔離字型與硬編碼色碼須依美術規範收斂對齊至 `css/tokens.css` 與劇場主題色變數。
- 所有新繪製或微調的 SVG 資產與 GSAP 戰鬥演出皆須遵守「呆萌玩具魔王」「思考期零干擾」與 `prefers-reduced-motion` 無障礙減敏規範。

# 僅支援電腦與平板視窗，不針對手機窄螢幕進行專屬適配

本專案（數字積木屋與數學冒險島）的核心教學互動包含多位數十進位積木、直式進退位網格、16:9 繪本地圖、兩步驟生活應用題板面與秘密樹屋互動空間，需要較寬裕的可視區域與大型觸控按鍵以確保國小二年級學童的閱讀清晰度與操作準確性。因此我們決定將目標裝置支援範圍明確限定為**電腦（桌機／筆電）與平板（橫向與直向）**，不針對手機窄螢幕（如寬度小於 `600px` 的手持電話版面）進行版面妥協、專屬開發或瀏覽器實機驗證。

## Considered Options

- **全尺寸響應式（包含 360px～430px 手機窄螢幕）**：需不斷折行或大幅縮小積木、算式與 16:9 地圖，會壓縮兒童觸控熱區並拉高維護與驗證成本，且並非本教具的主要使用設備（教室投影／家裡電腦與 iPad 平板）。

## Consequences

- 所有新元件的版面設計與 CSS 斷點僅需確保**電腦（如 `1280×800` 及以上）**與**平板橫直向（如 `1024×768`、`768×1024`）**佈局完整流暢、無溢位與重疊。
- 瀏覽器實機畫面驗證無須再納入 390px 等手機視窗測試。

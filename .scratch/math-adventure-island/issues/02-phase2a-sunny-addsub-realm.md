# [02] Phase 2a：陽光加減群島（5 島 15 關）、加減法引擎與單步生活應用題

## 目標說明

實作第一座全新海域「☀️ **陽光加減群島**」（5 座島嶼、15 個關卡、5 位新島嶼魔王、5 隻新守護小精靈），補齊加減法題庫引擎（二～三位數進退位、跨零退位、未知數反推）、單步驟生活應用題模板（購物合併、付錢找零、比多比少）與不變量驗證器、戰鬥舞台迷你直式對齊卡（含 3 位數鍵盤支援）、加減法與線段對照小幫手，並啟動「數學技能圖鑑」前 10 張技能卡（銅／銀／金升階）。

## 驗收標準（Acceptance Criteria）

1. 玩家在海域航行列可自由切換至「陽光加減群島」，並從 `sunny:1-1`（奶油麵包村）一路挑戰至 `sunny:5-3`（彩虹燈塔大魔王）。
2. 進退位、三位數加減與跨零退位題型顯示位值色碼迷你直式對齊卡（可切換橫式），數字鍵盤支援輸入 1～3 位數答案；答錯或開啟小幫手時正確顯示十進位積木拆解或比較線段圖。
3. 5 隻新守護小精靈擊敗對應魔王後可成功收服並跟隨出戰（本期先使用現有標準免費輔助與合體技，完整 4 大專長流派差異化於 Phase 3 實裝）。
4. 數學技能圖鑑可追蹤前 10 張加減／生活應用技能卡累積次數並正確顯示銅／銀／金階級。
5. `npm test` 與 `npm run build` 通過，並以實機瀏覽器驗證電腦與平板（橫／直向）寬度下迷你直式、5 島地圖節點與新底圖無跑版或遮擋（不支援手機窄螢幕）。
